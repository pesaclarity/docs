# Pesa Clarity docs

Pesa Clarity is a free, ad-free Android app, with an iPhone version in the works, that turns M-Pesa and bank messages into a clear daily plan: what you can spend today, what is due, where money leaks, and when you will be debt-free. All analysis runs on the phone; the server only signs users in, holds backups it cannot read, and combines federated model updates.

This repo is the source of truth for what we build and how it looks.

## Principles

1. **Free forever, no ads.**
2. **Your data stays yours, on your phone.**
3. **Plain answers, not spreadsheets.**
4. **Export in two taps.**
5. **Honest money maths.**
